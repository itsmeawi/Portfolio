How to set up in 3 minutes:

Step 1
Create Google Sheet & Open Apps Script:

Go to sheets.new, then in the top menu click Extensions > Apps Script.

Step 2
Paste Backend Code (Code.gs):

Replace existing code in Apps Script with the contents of Code.gs from this repository.

Step 3
Deploy as Web App:

Click Deploy > New deployment > Web app.

  • Execute as: Me
  • Who has access: Anyone (CRITICAL)

Authorize permissions, copy the Web App URL (ends in /exec), and paste it above!
